## 系统简介

硕士论文智能评审系统是一款基于 Python + LLM 混合架构的论文评审工具。

**核心设计原则**：Python 负责可量化指标，LLM 负责深度评价——各司其职，输出稳定可解释的评审报告。

---

## 技术架构

```
docx/PDF文件
    ↓
[1] 文档解析层 (Python) → 提取结构化文本
[2] 精准统计层 (Python) → 字数、文献数、论文类型
[3] 深度评价层 (LLM)   → 7维度深度评审
[4] 报告生成层 (LLM)   → 结构化评审报告
```
